# Интеллектуальная система персонализированной диагностики и развития критического мышления кадет

Автономный образовательный веб-тренажёр на Streamlit без OpenAI API. Постоянные данные кадетов, диагностика, история тренировок и диалоги наставника хранятся в Supabase PostgreSQL.

## Что сохранено

- Входная диагностика — **16 заданий из исследовательской работы без изменения формулировок и вариантов**.
- Профили А1/А2/Б/В не используются.
- После диагностики строится индивидуальная карта конкретных навыков.
- Формируется персональный план и адаптивная тренировка.
- Тренировочная база содержит задания, переданные пользователем из Google Forms.
- Автономный наставник работает без OpenAI API и оплаты.
- Результат входной диагностики не изменяется тренировочным модулем.
- Есть история прогресса и педагогическая панель с CSV-экспортом без ФИО.
- Коды кадетов и результаты больше не хранятся в локальном `cadets.db`, который мог исчезать после перезапуска Streamlit Cloud.

## Важно про тренировочные ключи

`data/training_tasks.json` содержит задания, переданные пользователем из Google Forms. В текущей базе поле `review_status` для тренировочных заданий указывает, что ключи требуют педагогической проверки. До конкурсного или исследовательского применения тренировочные ключи желательно валидировать и зафиксировать отдельно от входной диагностики.

## Подключение Supabase

### 1. Создайте проект Supabase

Создайте проект `cadet-critical-thinking`.

### 2. Создайте таблицы

В Supabase откройте **SQL Editor → New query**, вставьте весь файл `supabase_schema.sql` и нажмите **Run**.

### 3. Получите два значения

В Supabase откройте **Project Settings → API Keys**.

Нужны:

- **Project URL**
- **Secret key → default**

Секретный ключ нельзя публиковать в GitHub и нельзя вставлять в исходный код.

### 4. Streamlit Cloud

В приложении Streamlit откройте **Settings → Secrets** и добавьте:

```toml
SUPABASE_URL = "https://YOUR_PROJECT.supabase.co"
SUPABASE_SECRET_KEY = "YOUR_SECRET_KEY"
```

Сохраните Secrets и перезапустите приложение.

### 5. GitHub

Загрузите в репозиторий содержимое этого архива:

- `app.py`
- `requirements.txt`
- `supabase_schema.sql`
- `.env.example`
- `README.md`
- папку `data/`

Не загружайте реальный `.env` и реальные ключи Supabase.

## Локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Для локальной разработки можно создать `.env` по образцу `.env.example`.

## Если старый код кадета перестал работать

Это ожидаемо, если старый `cadets.db` был потерян при перезапуске Streamlit Cloud. Эта версия начинает постоянное хранение в Supabase. Старый код можно восстановить только если сохранилась копия старой базы `data/cadets.db`; сам Streamlit Cloud не гарантирует сохранность локального файла приложения.
