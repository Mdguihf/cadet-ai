# Cadet AI 4.0

Прототип образовательного AI-тренажёра по критическому мышлению для кадет.

## Что изменено
- Входная диагностика — 16 заданий из исследовательской работы, формулировки и варианты перенесены без изменений.
- Убраны профили А1/А2/Б/В.
- Убрана фиксированная система тренировочных уровней.
- После диагностики формируется карта конкретных навыков и индивидуальный план.
- Тренировочная база содержит задания, присланные пользователем из Google Forms.
- Адаптация учитывает предыдущие попытки и ошибки по навыкам.
- AI может объяснять ошибки, вести сократический диалог и генерировать дополнительное задание.
- Диагностический результат не изменяется AI.
- Есть педагогическая панель и CSV-экспорт без ФИО.

## Источники
`data/diagnostic_tasks.json` — задания из научной работы.
`data/training_tasks.json` — задания, присланные пользователем из Google Forms.
Для тренировочных заданий, где исходный ключ не был дан, поле `review_status` помечено как `model_inference` или `needs_teacher_review`. Такие ключи следует проверить педагогом до конкурсного/исследовательского применения.

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```

Для AI задайте переменные окружения `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL`. Не храните API-ключ в исходном коде.

## Ограничения
Это образовательный инструмент, а не клинический психологический сервис. Для научного исследования диагностический тест и тренировочные ключи должны быть валидированы и зафиксированы до сбора итоговых данных.


## Подключение AI локально

1. Создайте рядом с `app.py` файл `.env`.
2. Добавьте:
   `OPENAI_API_KEY=ваш_ключ`
3. При необходимости укажите модель:
   `OPENAI_MODEL=gpt-5.6-luna`
4. Выполните `pip install -r requirements.txt`.
5. Запустите `streamlit run app.py`.

Cadet AI автоматически загружает `.env` при старте. Сам файл `.env` не включайте в ZIP и не публикуйте.
